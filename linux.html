The saved window, unaltered.

On 22 October, Capture Window selected a labeled terminal in the live Wayland session. SnapDog saved a 1960 × 1094 PNG with its window shadow. We decoded and inspected it: the terminal is present, with no picker tint or fading menu in the pixels.

This is the output file from that test, not a replacement mockup. Read the 0.2.58 fix notes.

What passed on Omarchy.

Capture and editor

Live fullscreen, region, and window capture; editor Save and Copy; History thumbnails and reopening a saved image.

Screen recording

Record and Stop produced a 26.5-second H.264 movie. We decoded the file and inspected a later frame.

Installed Arch build

Version 0.2.58 passed installed smoke, 111 Linux tests, and a package check of 35 files with none altered.

This is a development build tested on one 1920 × 1080 Omarchy display. DEB and RPM archives passed package checks but have not been live-installed on their distributions. The host had no camera; physical hotkey delivery was not confirmed. The Mac App Store button is for the separate macOS release.
